# SoraFlux

Darmowy konwerter wideo, audio, obrazów i GIF-ów na Windows: przycinanie, cel w MB (np. Discord 10 MB), pobieranie z linku. Bez reklam, bez limitów, bez telemetrii.
Free video, audio, image and GIF converter for Windows: trimming, a size target in MB (e.g. Discord 10 MB), downloading from a link. No ads, no limits, no telemetry.

**[SoraFlux-setup.exe](https://github.com/cybersora9/soraflux-wydania/releases/latest/download/SoraFlux-setup.exe)** · Windows 10/11 (64-bit)

It's a program, not a website: double-click the downloaded file. If Windows says "Windows protected your PC": **More info → Run anyway**.

Strona / Website: https://cybersora.pl/soraflux/ · [Polityka prywatności / Privacy policy](https://cybersora.pl/soraflux/#prywatnosc)

Masz SoraFlux 1.4? Pobierz 2.0 raz stąd i zainstaluj na starą wersję (ustawienia zostają); kolejne aktualizacje przyjdą same.
Using SoraFlux 1.4? Download 2.0 once from here and install over it (settings are kept); later updates arrive automatically.
