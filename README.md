# SoraFlux

Darmowy konwerter wideo, audio, obrazów i GIF-ów na Windows: przycinanie, cel w MB (np. Discord 10 MB), pobieranie z linku. Bez reklam, bez limitów, bez telemetrii.
Free video, audio, image and GIF converter for Windows: trimming, a size target in MB (e.g. Discord 10 MB), downloading from a link. No ads, no limits, no telemetry.

**[SoraFlux-setup.exe](https://github.com/cybersora9/soraflux-wydania/releases/latest/download/SoraFlux-setup.exe)** · Windows 10/11 (64-bit)

## Co jest w tym repozytorium / What this repository holds

Tylko pliki wydań: instalatory, podpisy aktualizacji (`.sig`), `latest.json` dla aktualizacji w apce i sumy `SHA256SUMS.txt`. Kodu źródłowego tu nie ma.
Release files only: installers, updater signatures (`.sig`), `latest.json` for in-app updates and `SHA256SUMS.txt`. No source code.
